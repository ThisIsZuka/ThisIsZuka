### About me

Backend developer with 5+ years of experience, working mainly in **Go** for the last 2+ years.
I build microservices for e-commerce, retail and payment systems.

- 🛒 Currently building **order and payment services** in pure Go (no framework) for a large retail e-commerce platform
- 🧩 Built microservices with **go-zero**, distributed transactions with **DTM (Saga Pattern)** and service discovery with **Consul**
- 🎬 Built video streaming (HLS) on **AWS S3 / CloudFront** for an online course platform
- 💳 Integrated **payment gateways** with Thai banks during my PHP / Laravel years
- ✅ Write unit tests with dependency injection and mocks as part of everyday work
- 🌱 Learning now: Kubernetes, Go concurrency patterns, system design
